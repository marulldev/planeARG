"conexion_prueba.php" permite escribir consultas SQL desde la misma página
trae ejemplos de consultas rápidas como:

SELECT * FROM usuarios;
SELECT * FROM vuelos;
SHOW TABLES;

Un ejemplo comun de una consulta es:
SELECT * FROM vuelos WHERE id=1;
traducido al español seria:
SELECCIONAR <atributo> DE <tabla> DONDE <condicion>
